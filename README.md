👨‍💻 Sobre mim
Sou formado em Análise e Desenvolvimento de Sistemas e atuo no desenvolvimento e na manutenção de sistemas institucionais na CTINF/SESED-RN. Também sou sócio-fundador da POTIWEB, onde participo do desenvolvimento de soluções web para clientes.
